# Edwin Maduro — Portfolio Website

A responsive single-page portfolio for Edwin B. Maduro, positioned around UI/UX, product design and digital product experience.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual system and animations
- `script.js` — case-study modal, scroll reveals and light/dark theme

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment
The folder can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.
